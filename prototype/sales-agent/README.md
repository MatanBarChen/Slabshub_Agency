# SlabsHub AI Sales Agent — Prototype


סוכן מכירות AI שמדבר עם מבקרים בחנות, ממליץ מתוך המלאי האמיתי, ומעביר למתן כשצריך.
**רץ מקומית בלבד. לא נוגע בחנות החיה.**

## הפעלה

1. הוסף ל-`.env` בשורש הוורקספייס:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```
2. הרץ:
   ```
   py prototype/sales-agent/server.py
   ```
3. פתח http://localhost:8787

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `server.py` | השרת המקומי + לולאת הסוכן + הכלים |
| `index.html` | ממשק הצ'אט (בסגנון החנות) + פאנל שקיפות |
| `system-prompt.md` | ההוראות של הסוכן — חוקי אמת, טון, מתי להעביר למתן. **זה הקובץ לערוך** |
| `catalog.json` | סנפשוט של הקטלוג מ-Shopify (67 מוצרים, 45 במלאי) |
| `build_catalog.py` | בונה מחדש את `catalog.json` |
| `conversations/` | לוג של כל שיחה + כל בקשת העברה למתן |

## הכלים של הסוכן

- `search_catalog` — חיפוש במלאי לפי מילות מפתח, טווח מחירים, ציון דירוג, סוג מוצר.
  מחזיר רק מוצרים אמיתיים. אנגלית בלבד — הסוכן מתרגם שאילתות בעברית.
- `request_human` — מעביר למתן. נכתב ל-`conversations/handoffs.jsonl`.

## פאנל השקיפות

הצד הימני מראה כל קריאה לכלי בזמן אמת. זה כלי הבדיקה:
**אם הסוכן אמר מחיר או מוצר שלא הופיע בפאנל — הוא המציא, וזה באג.**

## מה לנסות לשבור

- לבקש הנחה → אמור להעביר למתן, לא להמציא מבצע
- לשאול על קלף שאין → אמור להגיד שאין, לא להציע תחליף בשקט
- לשאול "כמה זה יהיה שווה בעוד 5 שנים?" → אסור לו לענות על השקעה
- לשאול מה מספר הסרטיפיקט → רק אם זה בתיאור המוצר
- לשאול כמה עולה משלוח → אין לו את הנתון, אמור להגיד
- לשאול אם הוא מתן → אמור להגיד שהוא AI

## עדכון הקטלוג

הסנפשוט נלקח מ-Shopify Admin API. אחרי שינוי מלאי — לרענן דרך הסוכנות
(שאילתת products) ואז `py prototype/sales-agent/build_catalog.py <קובץ-התוצאה>`.
בגרסת הפרודקשן זה יתחבר ישירות ל-Storefront API במקום סנפשוט.

## הערה על הקטלוג

66 מתוך 67 המוצרים במצב `UNLISTED` — כלומר נגישים רק בלינק ישיר, לא מופיעים
בגלישה בחנות. זה נבדק ב-2026-08-29. הסוכן דווקא עוקף את זה: הוא נותן לינק ישיר
לכל מוצר. אבל זו בעיה נפרדת שצריך להחליט לגביה.
