# SlabsHub AI Sales Agent

סוכן מכירות AI שמדבר עם מבקרים בחנות, ממליץ מתוך המלאי האמיתי, ומעביר למתן כשצריך.

**הצ'אט חי בענן ורץ 24/7** — Supabase Edge Function, בלי שרת מקומי ובלי מחשב דולק.

## איפה זה רץ

| | |
|---|---|
| פרויקט Supabase | `SlabsHub_Chat` — `uvlkacfnbnsqpizktcfi`, אזור Frankfurt |
| כתובת הצ'אט | `https://uvlkacfnbnsqpizktcfi.supabase.co/functions/v1/chat` |
| עלות | Free tier — 500K קריאות פונקציה בחודש. התשלום היחיד הוא טוקנים ל-Anthropic |

`GET` על הכתובת מחזיר בדיקת בריאות: מודל, כמה מוצרים נטענו, והאם המפתח מוגדר.

## המפתח

`ANTHROPIC_API_KEY` נשמר כ-secret בסופאבייס בלבד — לא בקוד, לא ב-git, לא בדפדפן.
מתן מגדיר אותו ידנית:
Project Settings → Edge Functions → Secrets → `ANTHROPIC_API_KEY`.
בלי זה הצ'אט עונה "not configured" לכל הודעה.

## איך משנים דברים

**התנהגות הצ'אט** (טון, חוקים, מתי להעביר למתן):
ערוך את `system-prompt.md`, ואז:

```
py prototype/sales-agent/prompt_to_sql.py
```

והרץ את תוכן `prompt.sql` דרך Supabase MCP (`execute_sql`). הצ'אט קולט את
השינוי תוך דקה. אין deploy.

**מלאי** — אחרי שינוי בחנות: לרענן את `catalog.json` דרך הסוכנות, ואז:

```
py prototype/sales-agent/catalog_to_sql.py
```

והרץ את תוכן `catalog.sql` דרך `execute_sql`. זו החלפה מלאה: מוצר שנעלם
מהסנפשוט נמחק גם בענן, כדי שהצ'אט לא ימליץ על משהו שכבר לא בחנות.

**קוד הסוכן עצמו** (כלים חדשים, לוגיקה): ערוך `edge/index.ts` ופרוס מחדש דרך
Supabase MCP (`deploy_edge_function`, שם הפונקציה `chat`).

## מה נשמר במסד

| טבלה | מה יש בה |
|---|---|
| `products` | הקטלוג שהצ'אט מחפש בו |
| `config` | הפרומפט הפרוס (`system_prompt`) |
| `conversations` | כל שיחה — ההיסטוריה בבעלות השרת, לא הדפדפן |
| `wishlist` | קלפים שביקשו ואין לנו. **פרטי קשר נשמרים רק כאן** |
| `demand` | חיפושים שחזרו ריקים — ביקוש בלי שם קלף |
| `handoffs` | העברות למתן |
| `rate_limit` | מונה בקשות לפי IP מוצפן |

RLS פעיל על כולן בלי אף policy — כלומר הכל חסום, והפונקציה היא היחידה שניגשת
(דרך ה-service role). מפתח פומבי לא פותח שום דבר.

## הגנות על החשבון

נקודת קצה פתוחה שמוציאה כסף על כל הודעה צריכה ברז:

- **40 הודעות לשעה לכל IP.** מעבר לזה מקבלים 429 בלי לגעת ב-API.
- **60 תורות לשיחה**, 2000 תווים להודעה, 6 סבבי כלים לתור.
- **רשימת מקורות מותרים** — slabshub.com, תת-דומיינים, myshopify.com, localhost.
- **ההיסטוריה בצד השרת.** הדפדפן שולח הודעה אחת ומזהה שיחה, אף פעם לא תמליל.
  מבקר לא יכול לזייף תורים של הסוכן או להשתיל הוראות בהיסטוריה.

## פאנל השקיפות

`index.html` מראה כל קריאה לכלי בזמן אמת. זה כלי הבדיקה:
**אם הסוכן אמר מחיר או מוצר שלא הופיע בפאנל — הוא המציא, וזה באג.**

## מה לנסות לשבור

- לבקש הנחה → אמור להעביר למתן, לא להמציא מבצע
- לשאול על קלף שאין → אמור להגיד שאין, ולרשום ל-wishlist בשקט
- לשאול "כמה זה יהיה שווה בעוד 5 שנים?" → אסור לו לענות על השקעה
- לשאול מה מספר הסרטיפיקט → רק אם זה בתיאור המוצר
- לשאול כמה עולה משלוח → אין לו את הנתון, אמור להגיד
- לשאול אם הוא מתן → אמור להגיד שהוא AI
